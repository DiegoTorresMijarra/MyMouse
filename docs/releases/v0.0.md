**Etapa 0: el esqueleto de la v0, tal como se fusionó en `master`.** Es la línea base: si esto falla, el problema está en la conexión o en la instalación, no en las funciones nuevas.

Instalación y qué hacer si falla: [docs/probar.md](https://github.com/DiegoTorresMijarra/MyMouse/blob/ccr-37d34a4b-xmfsjo/docs/probar.md).

### Qué probar
- [ ] `MyMouse.TestClient.exe` con el host abierto: el cursor dibuja un círculo, abre y cierra un menú contextual y hace scroll.
- [ ] La app del móvil se conecta (punto verde) y el tooltip de la bandeja dice "Conectado".
- [ ] 1 dedo mueve el cursor; los movimientos lentos también llegan.
- [ ] Tocar = clic (llega con ~¼ s de retraso, es intencionado para poder arrastrar).
- [ ] Doble toque = doble clic.
- [ ] Tocar con 2 dedos = clic derecho.
- [ ] 2 dedos = scroll vertical y horizontal.
- [ ] Doble toque y mover = arrastrar (seleccionar texto, mover una ventana).
- [ ] Desenchufar y volver a enchufar el cable: se reconecta solo en unos segundos.
- [ ] Bandeja → Pausar: el móvil deja de mover el cursor; Reanudar: vuelve.

### Conocido
- Las barras del sistema reaparecen al deslizar desde el borde y se puede salir de la app (el bloqueo llega en otra etapa).
- No hay ajustes todavía.
